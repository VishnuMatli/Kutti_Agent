# Engineering Prompt for J.A.R.V.I.S. GUI Development

[Goal]:
Create a full-screen, high-fidelity engineering mockup and visual spec for a web-based, futuristic graphical user interface (GUI) modeled after the J.A.R.V.I.S. holographic display. This must capture all specific text, numbers, and data visualizations from the reference image.

[Design Language & Aesthetics]:

Background: Deep-space black.

Palette: Primary (J.A.R.V.I.S. Cyan/Blue, glowing), Secondary (Red/Orange accent, glowing), Tertiary (White/Gray, crisp).

Fonts: Futuristic, technical, sans-serif, high-legibility (e.g., 'Exo 2' or a custom tech font).

Elements: Transparent, semi-transparent panels, holographic glowing lines, sharp digital angles, wireframe structures.

Context: A sophisticated central AI console for Stark Industries.

[UI Component Specifications & Placement]:

I. Top-Level Status Bar (Header Panel)

L1 (Top-Left, STARK):

Text (L1): STARK (Bold, Red outline, Cyan fill). Below it, INDUSTRIES.

Text (L2): J.A.R.V.I.S. (Cyan). Below it, A.I. SYSTEM and ACTIVE.

Small ID Profile: Small user icon (e.g., small Tony Stark image) and text T. STARK / ID: TS-001.

C1 (Top-Center, RAM):

Text: RAM USAGE (Cyan) and 63% (Glow White). Dynamic line graph visualization below.

R1 (Top-Right, SYSTEM):

Buttons: SHUTDOWN, RESTART, LOG OFF (Cyan outline, Red text for Shutdown).

R2 (Far-Top-Right, DATE/TIME):

Date: 11 AUGUST (Large, Cyan).

Day: SATURDAY (Cyan).

Small Icon Grid: System tool icons (e.g., Chrome, PS, Recycle Bin, Skype).

II. Left Side Panel (Controls)

Label: Vertical text reading CONTROL PANELS.

Elements: Stacked button groups (Cyan outline). Text labels: CHROME, CONTROL PANEL, STEAM, WHATSAPP, uTORRENT, SKYPE. Each button has a glowing cyan state.

Vertical Gauge: On the far left edge, a vertical linear percentage gauge 0-100%.

III. Center Field (Main View)

Central Asset: Large, detailed, glowing line-art (wireframe) bust of the Iron Man Mark helmet and torso. The internal Arc Reactor must be prominently detailed and glowing red-orange. The helmet's eyes glow.

Contextual Dialogue (Above Helmet): J.A.R.V.I.S. (Cyan). Below, user command: What Can I Search For You, Sir? (White).

Search/Task List (Center-Left): Glowing text list: GOOGLE, GMAIL, FACEBOOK, YOUTUBE, IMDB, KAT, WEB, 9GAG, PIRATE BAY, STUMBLEUPON, YAHOO, PUPIL PAD, WIKIPEDIA.

Circular Blueprint 1 (Center-Left): Detailed mechanical blueprint of a servo-gear assembly (Cyan). Text overlay: UPTIME: 0d 20h 54m. List: CPU USAGE: 33%, D: 3.39 GB / 97.6 GB.

Circular Blueprint 2 (Center-Right): Blueprint of an engine assembly or propulsion unit (Red-Orange accent).

Full Body Wireframe (Center-Right): Three-view (Front, Back, Profile) full-body wireframe of the Iron Man armor. Text label: SYSTEM. Below, metrics: CPU USAGE 31%, RAM USAGE 63%, SWAP USAGE 61%.

Disk Usage Bar: Horizontal bar graph with text: DISK C:\ 47.4 GB / 97.7 GB used. Next to it: D:\ 0.0 GB / 0.0 GB used.

IV. Right Side Panel (Telemetry)

L1 (Top-Right, Weather):

Text: Humidity: %, Feels Like: *, Precipitation: %, Wind: 0 mph, Pressure: 0.0 bar, Sunrise: / Sunset:.

Text (Below): Today 30* Mostly Cloudy.

Text (Below): Tomorrow Aug 12 30*/27* Showers.

Text (Below): Monday Aug 13 30*/27* Rain Showers.

R1 (Right Edge, GAUGE): Large semi-circular gauge (Red/Orange segment). Integrated circular navigation menu. Labels: Gmail, XDA Forums, Sammobile, Twitter, Facebook.

R2 (System Metrics, Below Gauge): Smaller circular gauges and data fields. Text: 11:33. Text List: Downloads, Dropbox, Music, Rainmeter, Document, Pictures, Videos.

R3 (Sub-Systems, Center-Right): A circular radar/map projection with text: 54*C, Surat, IP: 185.175.94.143.

V. Bottom Panel (Console & Power)

L1 (Status Text, Center-Bottom): Currently power level is at 100 percent and holding steady. (Cyan/White).

L2 (Date/Uptime, Below L1): AM Days Left: 142, Weeks Left: 20, Months Left: 4, In Year: 2018 (Small text).

C1 (Time, Large): 11:33 (Large, Cyan). Small text below: 11:33.

R1 (Media Player, Far Bottom-Right): Small album art (glowing square) and text labels (e.g., song title/artist). Control buttons: Prev/Pause/Next. 0.4 MB.

[Functional Interactions to Include in Visual Spec]:

All data numbers (RAM, CPU, Disk, Time, Weather, Uptime) must be defined as variables intended to update dynamically.

All buttons and menu items should have specific hover states (brighter glow) and click states (flicker).

The Arc Reactor core must visually pulse.

The entire screen should include a subtle background network data flow effect.
